# ITI Tasks & Projects

A comprehensive collection of labs, tasks, and projects completed during the ITI (Information Technology Institute) training program. This repository serves as a centralized hub for various technologies, including web development, system administration, and computer science fundamentals.

## 📂 Project Structure

### 🌐 Web Development

#### Frontend
*   **HTML5 & CSS3:** Found in `html5/` and `client_side/day_css_1/`. Includes layouts with Flexbox, Grid, and Bootstrap.
*   **JavaScript:** Progressive labs from `client_side/js_day_1/` to `js_day_8/`, covering DOM manipulation, AJAX, and ES6+.
*   **Vue.js:** Modern frontend projects in `vueJs_projects/`.

#### Backend
*   **PHP:** Core PHP labs in `php/` and security-focused implementations in `app_security/`.
*   **Laravel:** High-performance web services using Laravel 13:
    *   `web_services/posts-management`: A robust post management system.
    *   `web_services/product-catalog-dashboard`: A full-featured product dashboard.
*   **Django:** Python-based web development in `django/books_store_project/`.

### 💻 Programming Languages

*   **Java:** Extensive collection in `java_projects/`, covering everything from basic algorithms to GUI applications (AWT/Swing) and Bookstore systems.
*   **Python:** Foundational and advanced scripts in `python/`.
*   **C++:** Focus on Object-Oriented Programming principles in `oop/`.

### 🏗️ Computer Science Fundamentals

*   **Data Structures & Algorithms:** Implementations of linked lists, stacks, queues, and various sorting/searching algorithms in `data_structure/`.
*   **Object-Oriented Programming:** Deep dives into OOP concepts (inheritance, polymorphism, abstraction) in `oop/` and `design_patterns/`.
*   **Software Engineering:** UML diagrams, use cases, and design documents in `swe/` and `agile_tasks/`.

### 🗄️ Database Management

*   **Relational (SQL):** ERD designs and SQL tasks in `database/`.
*   **NoSQL (MongoDB):** Practical labs using MongoDB in `mongodb_practice/`.

### 🛠️ Systems & Tools

*   **Shell Scripting:** Automation scripts and system utilities in `shell_scripts/`.
*   **Agile:** Documentation and tasks related to Agile methodology in `agile_tasks/`.

### 🤖 Generative AI

*   **GenAI:** Innovative labs exploring LLMs and RAG (Retrieval-Augmented Generation) systems in `gen_ai/`.

## 🚀 Getting Started

Since this is a multi-disciplinary repository, different sections have different requirements:

*   **Web (PHP/Laravel):** Requires PHP 8.4, Composer, and Node.js.
*   **Java:** Requires JDK 17+ and an IDE like IntelliJ or NetBeans.
*   **Python/Django:** Requires Python 3.10+ and `pip`.
*   **C++:** Requires a G++ compiler.
